# Экран уведомлений

«Always-on» экран только для уведомлений: когда экран выключен и приходит уведомление
от выбранного приложения (например, Telegram), включается чёрный экран. Первые секунды
по краю экрана бежит цветная рамка, а внутри гуляют иконки приложений, как логотип DVD.
Если уведомления пришли от нескольких приложений сразу, иконки гуляют вместе.

## Как получить APK

### Вариант 1. Android Studio
1. Open → папка `NotifyAod` → дождаться Gradle Sync.
2. Меню Build → Build Bundle(s) / APK(s) → Build APK(s).
3. Файл: `app/build/outputs/apk/debug/app-debug.apk`. Отправить на телефон и установить
   (разрешить установку из этого источника).

### Вариант 2. GitHub Actions (без Android Studio)
1. Создать репозиторий на GitHub и загрузить в него содержимое папки (вместе с `.github`).
2. Вкладка Actions → «Сборка APK» → Run workflow (или просто после push).
3. Когда сборка закончится, в разделе Artifacts скачать `NotifyAod-debug-apk`, распаковать и установить `app-debug.apk`.

## Настройка на телефоне
1. Выдать разрешения в самом приложении (сверху экрана, пока не будут ✓):
   - Доступ к уведомлениям (если переключатель серый: Инфо о приложении → ⋮ → «Разрешить ограниченные настройки»)
   - Поверх других приложений
   - Без ограничений батареи
2. Xiaomi / HyperOS (обязательно, иначе экран не запустится из фона):
   - Инфо о приложении → Другие разрешения → «Всплывающие окна в фоне» и «Экран блокировки» → разрешить
   - Автозапуск → включить
   - Экономия заряда → «Нет ограничений»
   - Закрепить приложение в списке недавних (замок)
3. Отметить приложения внизу списка и выбрать цвет рамки для каждого.
4. «Показать сейчас» для быстрого предпросмотра, «Тест через 5 секунд» для проверки с выключенным экраном.

## Что нового в версии 1.0
- Полностью переработанный интерфейс: карточки с иконками, ползунки с градиентом,
  подсветка включённых настроек, тёмный и светлый вид.
- Выбор темы приложения вверху: «Система» (по умолчанию), «Тёмная», «Светлая».
- Новая иконка приложения (призрак).
- Из стилей рамки убрана «Комета». Стиль «Две полосы» стал длиннее: полосы почти смыкаются,
  между ними остаются узкие просветы.
- Постоянный ключ подписи (`debug.keystore`): новые версии ставятся поверх старой без удаления.
  Если при установке система пишет о конфликте, один раз удалите старую версию.

## Эффект «Жидкий неон» (Liquid Neon Smoke)
Новый стиль в списке «Стиль анимации». Вместо рамки по краю экрана — полноэкранное
жидкое неоновое свечение: тонкая яркая линия горит на границе текучей маски,
вокруг неё несколько уровней мягкого ореола. Считается на GPU одним фрагментным
шейдером (OpenGL ES 2.0): fbm-шум → domain warping → fluid-маска → edge detection → glow.
Цвет берётся из цвета, выбранного для приложения. Ползунки «Яркость свечения» и
«Мягкость свечения» появляются, когда выбран этот стиль; «Скорость» и «Толщина»
общие с рамкой. Повторное уведомление не создаёт второй слой — запускается новая
волна и кратковременно ускоряется течение.

## Структура
- `Settings.kt` — модель настроек, DataStore, логика ночного режима (`QuietHours`)
- `AodNotificationListener.kt` — ловит уведомления, фильтрует по приложениям и времени
- `AodLauncher.kt` — запуск экрана из фона
- `AodActivity.kt` — чёрный экран, рамка, несколько иконок, включение дисплея, закрытие
- `BouncingIcon.kt` — анимация «DVD»
- `MainActivity.kt` — тема приложения и главный экран настроек (Compose)
- `Components.kt` — элементы интерфейса: карточки, переключатели, ползунки, выбор темы
- `ColorPicker.kt` — выбор цвета рамки (любой цвет)
- `FluidNeon.kt` — эффект «Жидкий неон»: GL-шейдер и компонент `NotificationFluidEffect`
